# Bucosa voting system prototype

Bugema University Congolese Students Association voting system prototype

## setup

1. fork
To fork a repository, you click the "Fork" button located in the top-right corner of the repository page

2. clone
To clone follow the below instructions

```bash 
git clone https://github.com/obadias-09/Bucosa-voting-system-prototype.git
```

then

```bash
cd Bucosa-voting-system-protype
```
then

```bash
git remote add upstream https://github.com/obadias-09/Bucosa-voting-system-prototype.git
```
3. create a feature branch

```bash
git checkout -b <branch-name>
```
4. edit
add your code or write your changes

5. push your changes
```bash
git status
```
```bash
git add .
```
```bash
git commit -m "summary of your changes"
```

```bash
git push -u origin <branch-name>
```
